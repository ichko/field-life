Each world is a random interaction matrix — drawn free, symmetric, antisymmetric, cyclic, one-against-the-rest or in pairs — and random scalars, run for 700 steps at 128² in a headless browser. It was kept if, near the end, it was still moving, had structure rather than a flat fog or one spike, kept its fluids somewhat apart, and had interfaces. The shortlist was then thinned for variety, so no two here are the same world twice. The small grid under each animation is the matrix: green pulls, red pushes, row towards column. The number is the score.

Each animation is 48 frames, 20 steps apart, from the seed. The page loads it at 256² with the same seed, so the blob start matches; a noise start will differ in detail.
