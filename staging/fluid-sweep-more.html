Twenty-five were kept for variety. The small grid under each animation is the matrix: green pulls, red pushes, row towards column. The number is the score.

Each animation is 48 frames, 20 steps apart, from the seed. The page loads it at 256² with the same seed, so the blob start matches; a noise start will differ in detail.
